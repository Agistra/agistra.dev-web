Agistra is a free, open-source multi-agent hub: a human "Team Lead" directs four AI agents —
Architect, Builder, Tester, and Router — through a real ticket lifecycle. This blog is where we
write about building and running it.

## The canonical original

We also post on X as [@AgistraHQ](https://x.com/AgistraHQ). When a thread there covers something
we've written up here, the thread is a summary — this page is the original. If you want the full
version of anything we've shared on X, this is where it lives.

## What to expect

Posts here will cover the decisions behind the hub — how the agent lifecycle works, what we
change and why, and what we learn running Architect, Builder, Tester, and Router on real tickets.
No newsletter and no comments yet; for now, this is just where the writing lives.

## Try it yourself

If you want to see the hub run a ticket for real rather than just read about it, start with the
[quickstart guide](/docs/quickstart/). It walks through cloning the hub, opening it in your tool
of choice, and adding your first project.
