In the meantime, clone the hub and read the [README](https://github.com/vsetchinfc/agistra.dev#readme) for setup instructions:

```
git clone https://github.com/vsetchinfc/agistra.dev.git my-hub
cd my-hub
```

Then open `my-hub` in Claude Code, Cursor, GitHub Copilot, or Codex — agent definitions for all four ship out of the box.
